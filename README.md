# Clear Focus

A small Obsidian plugin that removes focus from selected UI fields when Obsidian loses application focus.

This prevents dropdowns from unexpectedly reappearing when returning to Obsidian and reduces accidental selections.

Created as a workaround for [this issue](https://forum.obsidian.md/t/dropdowns-are-hidden-when-obsidian-loses-focus-causing-missclicks/117676).
